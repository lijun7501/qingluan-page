更新日志

一直在改的，是真实用出来的问题

每一条都来自真实图纸：出图不对、册子散了、字折错了行。

v2.9.27 当前版本 最新
  • 中文 Windows 打印机列表可能为空：打印机枚举子进程输出未指定编码，含特殊字符的打印机名解码失败后异常被静默吞掉。现强制按 UTF-8 解码并容错替换，打印列表恢复完整。
v2.9.26成册与句柄修复
  • 自然语言描述成册失效：「自然语言描述成册」的意图被写进废弃的配置对象，对最终输出静默无效；现改为作用于本次任务实际使用的配置，描述成册恢复生效。
  • 句柄耗尽：批量读取 PDF 元数据 / 文本与自检核对时文件句柄未关闭，大批量作业会耗尽系统句柄；现统一改为上下文管理器即时释放（共五处）。
v2.9.25健壮性修复
  • 一批稳定性问题：新建 Excel 报表崩溃、界面自检卡死（改为后台线程池异步执行）、打印份数不生效、中文字体名被误判为 SHX 导致出图豆腐块、非十六进制颜色中断整页渲染、旧版配置键静默丢失、空分组排序崩溃、多页 PDF 成册时目录页次串号、「整批成册」开关不生效、旋转图框出图被放大 100 倍、PDF 读取句柄泄漏、字体别名临时目录残留，均已修复。
v2.9.24 折行修复 修复
  • 多行文字折行三处隐性失效：\L \O \K 等单字符命令被误当带参命令，把后文一路吞到下一个分号，长段落被判成「很短」而不折行；\U+00B0 转义同样吞后文；\S1/2; 堆叠分数分子分母不计入宽度。现已按 ezdxf 单字符命令表解析，字距按实测校准，行尾不再被单元格右边框切掉。
  • 地层代号标签印成纯黑块：多行文字的背景遮罩本应用纸面底色压住穿过文字的地形线，却被单色出图策略一并改黑。现只对带遮罩的多行文字填充开一条不参与单色化的通道。
  • 报表幅面尺寸空白：矩形 / 图层策略的图框没有图幅实体，出现「幅面 = A3、宽高空白」。现按幅面代号回退标准尺寸，支持 A3+2 等加长幅面。
  • 图签注释补 /P 页面引用，注释读取同时支持路径与内存流。
v2.9.22公路图签新增
  • 公路工程图签按图签栏几何自动识别，写入 PDF 隐藏注释并旁挂 .meta.txt。
  • 图签项目名称参与工程类型判定；公路项目封面编制依据自动引用交公路发〔2007〕358 号。
v2.9.21连页图修复
  • 同一图纸内多套总页数相同的连页图页序不再交错，按页号分桶还原系列号。
  • 图框内正文「详见第 5 页」不再被误判为页码；命名模板 {pages} 不再导致各页同名覆盖。
v2.9.18成册修复
  • 成册页（封面 / 扉页 / 图纸目录 / 封底 / 卷内备考表）按规范自动生成并挂载本册图签字段。
  • 修复多册成册时工程名称 / 设计单位跨册串用；每册恰好一套成册页。
v2.8.7许可重构
  • 完全移除 PyMuPDF，出图链路改用自研 PDF 内容流后端 + pypdf + reportlab，闭源专有分发不再需要商业许可。
