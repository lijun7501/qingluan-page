所有图纸格式都能直接用吗？
DXF 等开放格式图纸免转换器可直接出图；CAD 原生二进制图纸需先经「图纸摆渡」等兼容转换器（ODA File Converter / 中望·浩辰 / AutoCAD 均可），首次启动向导会手把手教你安装与接入。
为什么不用 OCR 识别图签？
OCR 易错且需人工校对。青鸾改用「隐藏注释机制」：出图时把图签字段写入隐藏注释，导入优先读取，识别又快又准，因此也得以剔除笨重的 OCR 组件，安装包约 220MB。
AI 辅助识别需要额外配置吗？
可选。填写 OpenAI 兼容接口的 API Key（默认 DeepSeek，也可用通义、豆包等）即启用大模型纠错、补全与逻辑校验；不填 Key、调用失败或超时都会自动降级为规则引擎，不影响成册主流程。
内网 / 无网环境能用吗？
可以。绿色版解压即用、删除即卸载，不依赖联网；适合内网、保密环境与便携部署。
成册都包含哪些内容？
自动识别 14 类图签字段，按工程、子项、阶段、专业逻辑分册，装配封面、扉页、图纸目录、封底、卷内备考表，一键导出整册 PDF，并可选生成 Excel 图纸目录 / 一览表。
